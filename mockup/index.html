    How installing works

    Most apps here are shell scripts that run on the router itself. You need SSH access, which every GL.iNet router has out of the box.

    Connect via SSH

    Open a terminal and log in with your admin password. The default router address is 192.168.8.1.

    Run the installer

    Press Install on any app. You get its command with a copy button, plus what to check before you run it.

    Follow the prompts

    Most scripts ask before they change anything and explain how to undo it. Details are in each project's README.

    These are community projects, not GL.iNet software. Read a script before you run it, keep a configuration backup, and expect a firmware update to undo some changes.

    Add your project

    Built something for your GL.iNet router?

    Open an issue in the community Issues repository with a link to your project. The maintainers fork it into the organization and keep the fork in sync with your repository. Once a short description is added, it appears here. You keep ownership and credit.

    • Open-source licence and a public repository
    • README with install steps and supported models
    • A way to undo what the script changes
    • Tested on real hardware, with the firmware version noted
